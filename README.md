# 燼守關 Ember Pass — 微18禁 iOS 版

性感魔女主題塔防遊戲，已優化為 iPhone / iPad 可加入主畫面的 PWA。

## 如何在 iPhone 上玩（全螢幕 App 體驗）

1. 用 **Safari** 開啟 `index.html`（或上傳到任意靜態主機）
2. 點底部「分享」按鈕
3. 選擇「加入主畫面」
4. 從主畫面圖示進入即可全螢幕、無瀏覽器工具列遊玩

## 遊戲特色

- **4 位性感魔女**作為砲塔：
  - 餘燼魔女（基礎）
  - 烈焰魔女（範圍灼燒）
  - 彈幕魔女（超高射速）
  - 寒霜魔女（減速）
- Canvas 手繪曲線身材 + 表情細節
- 粉紅 / 紫紅性感色調
- 15 波敵人 + Boss
- 觸控友善、支援安全區域（劉海 / Home Indicator）
- 遊戲速度 ×1 / ×2 / ×3

## 操作

- 點選下方魔女 → 點擊空地召喚
- 點擊已召喚的魔女可解散（退 60% 餘燼）
- 點「下一波」出兵

## 技術

純 HTML5 Canvas + Vanilla JS + PWA Manifest  
無需建置、無需 App Store，直接在 iOS Safari 以近似原生 App 方式運行。
